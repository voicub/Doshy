# Doshy

Isometric 3D dashboard and home design tool for Home Assistant: draw your home, place your devices, and control them from the plan.

- Runs next to Home Assistant and talks to it through the Supervisor: no access token to create.
- Open it from the add-on page (**Open Web UI**), or put it in the sidebar with the Doshy integration (HACS, see the repository README).
- Your plans, settings and imported models are stored in the add-on's own data folder and are part of Home Assistant backups.

Setup, options and limits: see the **Documentation** tab.
